# COSMOS Mainsail Theme V4

Theme assets for the OpenCentauri COSMOS project.

## Contents
- `custom.css`: dark glass / 3D Mainsail styling.
- `cosmos-starfield.svg`: text-free vertical starfield wallpaper with nebula and planetary horizon.

## Install
Copy the contents of this directory to the Mainsail theme directory, normally:
`~/printer_data/config/.theme/`

Enable the custom theme in Mainsail if required by the installed Mainsail version, then hard-refresh the browser (Ctrl+Shift+R).

This theme only changes presentation. It does not modify Klipper, Moonraker, printer configuration, GPIO assignments, or firmware behavior.
